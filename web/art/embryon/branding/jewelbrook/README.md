# Jewel Brook — approved splash art (staged)

**Public title:** Jewel Brook: Heroes of Embryon. **Source:** the user-approved final composite image, not a regenerated Daysha, and no unapproved dog.

The production crops were extracted losslessly by region but WebP-encoded at quality 94. The original sheet and eight crops are available in the approved transfer archive, which has been uploaded to the existing project art-source Google Drive folder. The binary files are **committed to GitHub on both `main` and `google-play`**; the manifest deliberately lists the source-transfer state as `github-committed`.

All eight vetted `.webp` files were added from the SHA-256/CRC32-verified source transfer. The importer is retained for reproducibility. Existing functional Android/Windows/Linux release checks remain authoritative; no cosmetic CI tests.

The approved image binaries are committed. Integration into the live title/loading UI is tracked separately; do not claim an image is displayed until the runtime reads it.
