# Jewelbrook display branding — Google Play branch

The public game name is **Jewelbrook** (previously Rupee Rush). This branch deliberately retains the existing Android package identifier, Google Play Games project identity, cloud-save integration, signing and upload-key configuration, save keys, and existing historical APK/release filenames.

Play-specific UI, launcher labeling and accessible name must match Jewelbrook. The retired title raster is kept as archived artwork, but the live home menu now uses a Jewelbrook text wordmark over the established Embryon background.

This Google Play branch is independent of the primary APK release branch and must preserve its store compliance diagnostics. Do not rewrite platform-specific IDs or disable functional release checks during rebranding. Do not add cosmetic release-blocking tests.
